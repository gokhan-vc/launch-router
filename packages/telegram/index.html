What people and machines can do

People

A wallet. A form. A signature. That’s the whole human path.

Mini App

launch.numetal.xyz/app.html — pick pad, chain, name, ticker. Advanced knobs stay visible; the matrix warns if a pad ignores them.

Connect

Browser wallet, WalletConnect, or Telegram (Privy embedded EVM wallet). Official Telegram @wallet is TON and cannot sign these deploys.

Simulate, then sign

Simulate shows the object your wallet signs — not a REST argument. Live Sign: Clanker (SDK), Bankr (your user API key, 57% split check, no partner keys), pools.fun (wallet sends PartyFactory.launch). Unproven pads are blocked.

Telegram

Bot /start opens the Mini App. Chat cannot broadcast. You still sign.

Machines

Free discovery. User still signs. Amount 0 on x402 and MPP.

MCP

POST /mcp JSON-RPC, or stdio npx tsx packages/mcp/src/stdio.ts. Tools: list_pads, list_networks, get_capabilities, draft_intent, simulate_launch, get_sign_payload. There is no broadcast.

REST

POST /api/v1/{tool} — body is the tool arguments. Same kernel as the Mini App.

Skill

/skill.md for Cursor, Claude, Grok, Codex, Aeon (category: crypto, mode: read-only). Unattended Aeon notifies the sign payload and stops.
